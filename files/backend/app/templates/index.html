    Wipe detection logs
    
          
    Clears OpenAMD database call logs (PostgreSQL) and matching WAV files under /opt/openamd/recordings so recordings are not left orphaned on disk. VICIdial itself is not modified.
    
          
    
          
    
            
            
            
            
            
            
    
          
    
        
    
      
    

      
    
        
    
          
    Audio cleanup
    
          
    Deletes WAV files stored under /opt/openamd/recordings to free disk space on the AI AMD server.
    
          
    
          
    
            
            
            
            
            
            
    
          
    
        
    
      
    

      
    
        
    
          
    Recording retention cron
    
          
    
            Tell the system how many days to keep recordings. A daily server job deletes older WAV files automatically
            (systemd timer at ~02:15). You can also run cleanup now.
          
    
          
    
            
            
            
            
            
            
    
            
    
          
    
        
    
      
    

      
    
        
    
          
    AMD confidence gate
    
          
    
            Only calls the AI marks HUMAN with confidence at or above this minimum are passed to
            VICIdial agents. HUMAN calls below the minimum are downgraded (e.g. to MACHINE) and are not connected.
            Controlled here on the AI AMD server — no changes needed on any VICIdial dialer.
          
    
          
    
            
            
            
            
            
            
            
    
              When enabled, empty or near-silent recordings are marked MACHINE and are not passed to agents.
              Disable to use the old behavior (blank calls may go to agents as HUMAN).
